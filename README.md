# linux-Assingment-3

🌟 Shell Scripting Assignment

📌 Overview

This project contains two shell scripts:

Part A: Draw different star patterns based on size and type

Part B: Print tom, cat, or tomcat based on number divisibility

# 📁Project Structure

1. drawStar.sh
  
2. printTomcat.sh
   
3. screenshots
   
4. README.md

# ✨ Part A: Star Pattern Generator

📝 Script Name

 # drawStar.sh

 ▶️ Usage

 #chmod +x drawStar.sh
 
#./drawStar.sh  (size) (type)


#📥 Arguments

size → Number of rows (example: 5)

type → Pattern type (t1 to t7)

# 🐱 Part B: Tomcat Problem

# 📝 Script Name

printTomcat.sh

▶️ Usage

#chmod +x printTomcat.sh

#./printTomcat.sh <number>

# ⚙️ Logic

If number dividible by 7 → no output


If number divisible by 3 → print tom


If number divisible by 5 → print cat


If divisible by 15 → print tomcat

#./printTomcat.sh 7
#./printTomcat.sh 6
#./printTomcat.sh 10
#./printTomcat.sh 30
